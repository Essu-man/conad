# Conad Tech Application Installers

Place your compiled Windows executable (.exe) installer files here:

- `Conad-POS-Setup-v3.2.0.exe` (Default installer for Conad POS terminal software)
- `Conad-Inventory-Setup-v3.2.0.exe` (Default installer for Conad Inventory management system)

The download route at `/api/download/[slug]` will automatically serve these files with proper attachment download headers.
